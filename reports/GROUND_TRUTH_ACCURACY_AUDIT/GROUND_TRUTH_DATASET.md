## 1. Dataset Design Principles & Epistemic Honesty

In accordance with Section 1 and Section 4 of the Master Verification Specification:
1. **Independent Establishment:** Ground-truth values were established independently prior to executing any OCR or LLM extraction. At no point was ground truth generated by copying model predictions or OCR outputs.
2. **Four-Stage Comparative Analysis:** Each document is tested through four stages:
   - **Stage 1 (Source Document):** The original pristine document ground truth.
   - **Stage 2 (OCR Output):** What the production Tesseract OCR engine actually transcribes.
   - **Stage 3 (AI Extraction):** What the real local Gemma 4 model (`gemma4:latest`) extracts from the OCR text.
   - **Stage 4 (Application Result):** What the downstream deterministic engines and UI present to the user.
3. **Epistemic Classifications:** Every ground-truth field is classified as:
   - `PRESENT`: Explicitly stated in the document with verbatim source citation.
   - `ABSENT`: Factually unmentioned in the source; system must abstain from hallucinating.
   - `AMBIGUOUS`: Inherently unclear formatting (e.g. `04/05/2026`).
   - `CONFLICTING`: Notice contains mutually contradictory statements in different sections.

## 3. Ground-Truth Data Structure

The ground truth schema stored in `reports/GROUND_TRUTH_ACCURACY_AUDIT/ground_truth.json` defines for each test document:
- `doc_id`: Unique identifier (`DOC-01` to `DOC-24`).
- `category`: The test condition stress category.
- `filename`: Relative path in `documents/`.
- `format`: `PDF` or `PNG`.
- `language`: `en`, `hi`, or `bilingual`.
- `page_count`: Number of physical document pages.
- `issuing_authority`: Expected authority name and verbatim citation quote.
- `notice_title`: Expected notice title.
- `notice_reference_number`: Expected circular reference ID.
- `publication_date`: Expected issuance date.
- `final_deadline`: Expected final submission deadline.
- `eligibility_percentage`: Expected minimum percentage marks.
- `eligibility_degree`: Expected qualifying academic degree.
- `eligibility_age_limit`: Expected upper age limit.
- `application_fee`: Expected fee payable.
- `official_portal_url`: Expected official web link.
- `contact_email`: Expected helpline email address.
- `contact_phone`: Expected helpline telephone number.
- `absent_fields`: Explicit list of fields that are completely absent.
- `ambiguity_reason`: Reason for ambiguity if applicable.
- `expected_action_items`: Ordered list of mandatory action items.
- `example_profile_evaluations`: Ground-truth eligibility verdicts (`PASS` or `FAIL`) for specific test profiles.
- `expected_revision_diffs`: Expected field-level changes for revision test cases.
